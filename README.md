`intellectorboard` is a library implementing the core rules and data model of the Intellector board game:

- hex/piece/ply primitives (`primitives`)
- position and piece arrangement (`position`)
- movement rules including premoves (`movement`)
- ply materialization and application (`plyapplication`)
- notation/label formatters (`mappers`)

All source lives under `src/intellectorboard` (`intellectorboard` package and its subpackages).
